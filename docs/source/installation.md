# Installation

pyHECTR supports Python **3.9–3.12**.

Use a fresh virtual environment when possible. This avoids mixing beamline,
notebook, PyTorch/CUDA, and system Python packages.

## Create and activate a virtual environment

### Linux/macOS

```bash
python3 -m venv pyhectr-env
source pyhectr-env/bin/activate
python -m pip install --upgrade pip
```

### Windows PowerShell

```powershell
py -m venv pyhectr-env
.\pyhectr-env\Scripts\Activate.ps1
python -m pip install --upgrade pip
```


## Core package

From PyPI:

```bash
python -m pip install pyhectr
```

From GitHub:

```bash
python -m pip install \
  "pyhectr @ git+https://github.com/batradiik/pyHECTR.git"
```

## Full scientific/optional stack

The EBSD/polycrystal, HDF5/Eiger, and neural-network helper workflows need additional
PyPI dependencies:

```bash
python -m pip install "pyhectr[full]"
```

PyTorch, torchvision, and Detectron2 are not installed automatically by pyHECTR.

## Jupyter

Install notebook support:

```bash
python -m pip install "pyhectr[full]"
```

Register the virtual environment:

```bash
python -m ipykernel install \
    --user \
    --name pyhectr \
    --display-name "pyHECTR"
```

Select **pyHECTR** in JupyterLab.

## Detectron2 / Mask R-CNN

Install the `full` pyHECTR extra first:

```bash
python -m pip install "pyhectr[full]"
```

Then install a PyTorch/torchvision build appropriate for your machine. For CUDA
systems, use the command generated by the official PyTorch selector:

<https://pytorch.org/get-started/locally/>

A simple CPU installation may be:

```bash
python -m pip install torch torchvision
```

Then install Detectron2:

```bash
python -m pip install \
  "git+https://github.com/facebookresearch/detectron2.git"
```

Check the environment:

```bash
python - <<'PY'
import torch
import detectron2

print("PyTorch:", torch.__version__)
print("CUDA available:", torch.cuda.is_available())
print("Detectron2 import: OK")
PY
```


## Development installation

```bash
git clone https://github.com/batradiik/pyHECTR.git
cd pyHECTR

python3 -m venv .venv
source .venv/bin/activate

python -m pip install --upgrade pip
python -m pip install -e ".[full,dev]"
```
